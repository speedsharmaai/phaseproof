# Security

Report a vulnerability through GitHub's private reporting: the **Security** tab of this repository, then **Report a vulnerability**. Please don't open a public issue for it.

You can expect a first reply within 7 days. Fixes ship as a new version in `plugin.json` and a note in `CHANGELOG.md`.

The hook and the gate script are plain Node with no dependencies. See the README section "What it runs and sends" for everything the plugin executes.
