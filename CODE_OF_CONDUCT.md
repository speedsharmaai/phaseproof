# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the work, and no harassment of any kind.

Report unacceptable behaviour privately to speedsharma.ai@gmail.com. Reports are read by the maintainer and kept confidential. The maintainer may remove comments, issues or contributions that break this code, and may block repeat offenders.
